If you use AI for the same job every week, you end up typing the same background every time: who it's for, how you like it written, the facts it keeps needing. [Does it remember me?](/ai-guides/does-it-remember/) has one fix: start a new <Term id="conversation">chat</Term> with a two-line summary. A project saves you from writing that summary at all.

## What a project is

A project is a saved space for one ongoing job. You give it standing instructions and a few files once, and every new chat you start inside it begins with them. The apps call it different things (Projects in ChatGPT and Claude, Notebooks in Gemini and Copilot), but the idea is the same.

It isn't the same as saved <Term id="memory">memory</Term>. Saved memory is what the app keeps about you everywhere. A project keeps what one job needs, and only inside that project. It isn't one long chat, either: each chat in a project starts fresh with the project's instructions and files, so it doesn't slow down or blur the way a very long chat does.

Here is the difference. Same job, same answer, two ways to get there. The example text is made up.

## An example: my toddler's naps

This is the project I use most. My toddler's sleep is hard to predict, so I keep a project for it.

- **The instructions:** her age, how we parent, the gear we use (blackout curtains, a white-noise machine), and "suggest a next nap time and a wake-up time, and say why in one line".
- **When I need it:** I take a screenshot of the nap-tracking app and ask, "When should her next nap be?" It already knows everything else.

Notice what's not in it: her name, her photo, where we live. It doesn't need them. And this is a low-stakes job: it's a suggestion, I can overrule it, and a nap that runs a little long costs nothing. I wouldn't hand a project anything where a wrong answer is expensive without checking it.

## What to put in one

Put in what you'd otherwise retype: who it's for, how you want the answer, the facts that don't change, and a reference file or two (a menu you're planning around, a style guide, a price list). Keep it short. Leave out anything you wouldn't paste into a chat. A project's files are kept with your account until you delete them. [What's safe to paste into AI](/ai-guides/never-paste/) has the list.

## Does it use more of your allowance?

The project's instructions and files are read again with each chat, so a project full of big files uses your allowance faster, just like attaching them every time. ChatGPT says credits and usage charges apply to project chats "the same as" regular chats. Claude says project content is cached and counts less when reused. The others don't say. [You've reached your limit](/ai-guides/usage-limits/) explains the <Term id="usage-limit">allowance</Term>.
